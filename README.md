# Buku Saku Kredit Perbankan

Website satu halaman yang merangkum materi perbankan tentang kredit/pinjaman:

1. Pengertian & unsur kredit
2. Tujuan & fungsi
3. Jenis-jenis kredit (KPR, KKB, KTA, KUR, dll.)
4. Prinsip analisis 5C, 7P, 3R
5. Prosedur pemberian kredit
6. Agunan & pengikatan jaminan (Hak Tanggungan, Fidusia, Gadai, Hipotek, Borgtocht)
7. Bunga flat, efektif, anuitas + **simulasi angsuran**
8. Kolektibilitas (POJK 40/2019) + **cek kolektibilitas dari hari tunggakan**
9. Kredit bermasalah & penyelamatan 3R
10. Rambu regulasi (BMPK, NPL, LDR/RIM, LTV, SLIK)
11. Pembiayaan syariah sebagai pembanding
12. Glosarium dengan pencarian
13. Kuis 10 soal

## Cara membuka

Tidak perlu build. Buka `index.html` langsung di browser, atau aktifkan
GitHub Pages (Settings → Pages → branch ini, folder root).

Angka ketentuan (BMPK, PPKA, LTV, KUR) dapat berubah; selalu rujuk regulasi
terbaru dari OJK dan Bank Indonesia.
